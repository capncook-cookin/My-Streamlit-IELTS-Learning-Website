# My-Streamlit-IELTS-Learning-Website
Working on an IELTS learning website that can make real impact
## Features
- Reading practice
- Writing practice
- Progress tracking
- AI coaching/chatbot
## Tech Stack
- Pyhon
- FastAPI
- Dotenv
- Unicvron
- Ollama AI
## Status
- Under active development
##Requirements:
1. Python 3.x
2. Ollama ( optional )
3. node.js
##How to open :
- cd to the backend folder, install all the requirement into that terminal ( pip install -r requirement.text )
- uvicorn main:app --reload
- cd to frontend folder then npm install then npm run dev ( you should got a localhost link, paste it into your browser )
